# Event FAQ

## Timing
The main event starts at 6:00 PM on Saturday and runs until 11:00 PM.
Doors open one hour early at 5:00 PM for early check-in.

## Location
The event is held at the Grand Hall, 45 Via Roma, Milan. Parking is available
in the adjacent garage, entrance on Via Torino.

## Logistics
Tickets are checked via QR code at the main entrance. Lost tickets can be
reissued at the help desk with a valid photo ID. The venue is wheelchair
accessible via the side entrance on Via Torino.
